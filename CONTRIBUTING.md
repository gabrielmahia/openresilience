# Contributing to OpenResilience Kenya

Thank you for your interest in contributing! This project serves Kenya's communities with water and agricultural resilience monitoring.

---

## 🤝 **How to Contribute**

### **We Welcome:**
- 🐛 Bug fixes
- ✨ New features
- 📝 Documentation improvements
- 🌍 Translations (especially Kiswahili!)
- 🧪 Test coverage
- 🎨 UI/UX enhancements
- 📊 Data quality improvements

## 📋 **Contribution Process**

1. Fork & Clone
2. Create Feature Branch
3. Make Changes (follow code style)
4. Test Locally
5. Commit with Clear Messages
6. Push & Create Pull Request

---

## 🎯 **Code Quality Standards**

- Write clear, self-documenting code
- Add docstrings to functions
- Use type hints where helpful
- Test before submitting

---

## 🌍 **Community Values**

- **Community First** - Serve farmers, not corporations
- **Data Sovereignty** - Communities own their data
- **Accessibility** - Works on basic phones
- **Open** - Share knowledge freely
